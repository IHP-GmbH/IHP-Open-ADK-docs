usage: run_drc.py [-h] --path PATH --interposer-adapter INTERPOSER_ADAPTER
                  [--interconnect-adapter INTERCONNECT_ADAPTER]
                  [--list-adapters]
                  [--interconnect-methods INTERCONNECT_METHODS]
                  [--topcell TOPCELL] [--run_dir RUN_DIR] [--threads THREADS]
                  [--run_mode {tiling,deep,flat}] [--report REPORT]
                  [--manifest MANIFEST] [--legacy-exchange0]

Run ADK assembly DRC checks via KLayout

options:
  -h, --help            show this help message and exit
  --path PATH           Path to the input GDS/OAS file.
  --interposer-adapter INTERPOSER_ADAPTER
                        Interposer adapter: a registry id (see
                        docs/adapter_contract.md); resolved through the ADK
                        registry only. A path is refused.
  --interconnect-adapter INTERCONNECT_ADAPTER
                        Optional interconnect adapter: a registry id (see
                        docs/adapter_contract.md); resolved through the ADK
                        registry only. A path is refused. Adds the bump-to-
                        bump pitch/spacing axis (IXN rules). Omit for
                        interposer-only checking (identical to before this
                        axis existed).
  --list-adapters       List the registered adapter ids with their decks and
                        the registry that supplied each, then exit.
  --interconnect-methods INTERCONNECT_METHODS
                        Optional per-method interconnect file (<gds-
                        stem>.ixn_methods.json, emitted by the exporter from
                        the .chiplet's per-die connections + the interconnect
                        PDK manifest). Scopes the IXN checks per method: each
                        method's pitch/spacing runs on the attachment pads
                        under ITS dies' boundaries, plus a conservative cross-
                        method spacing check. Requires the boundary manifest.
                        Without it the IXN axis stays assembly-global.
  --topcell TOPCELL     Top-level cell name (auto-detected if omitted).
  --run_dir RUN_DIR     Output directory for reports (default: timestamped
                        subdir in cwd).
  --threads THREADS     Threads per KLayout invocation (default: 4).
  --run_mode {tiling,deep,flat}
                        KLayout execution mode (default: tiling).
  --report REPORT       Explicit report path (overrides default naming).
  --manifest MANIFEST   Boundary manifest sidecar (<gds-
                        stem>.boundaries.json). Auto-discovered next to --path
                        if omitted. Holds the chiplet boundaries the assembly
                        DRC checks (PDK-agnostic; not a fab layer).
  --legacy-exchange0    Compat mode: read chiplet boundaries from the
                        historical exchange0 fab layer in the GDS instead of a
                        manifest (for pre-migration assemblies).

Examples:
  run_drc.py --path design.gds --interposer-adapter intm4tm2
  run_drc.py --path design.gds --interposer-adapter intm4tm2 --interconnect-adapter ihp_cupillar
  run_drc.py --list-adapters
